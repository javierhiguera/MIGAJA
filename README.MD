# Migaja - Milanesas Caseras

Web app for ordering homemade chicken milanesas. Built with vanilla HTML, CSS, and JavaScript.

## Features
- Product catalog with categories and search
- Shopping cart with local storage
- Checkout flow with delivery/pickup scheduling
- WhatsApp integration for order confirmation
- Supabase integration for order tracking

## Tech Stack
- HTML5
- CSS3 (Custom Properties)
- Vanilla JavaScript (ES6+)
- Supabase (Database)
- GitHub Pages (Hosting)
